Project Title

Product Data Exploration using Excel

Description

This project is an Excel-based product data analysis assignment.
The dataset contains product details such as Product ID, Product Name, Brand Name, Price, Quantity, and Category.

The purpose of this project is to perform basic data exploration and analysis using Excel formulas and functions. It helps in understanding product categories, pricing, quantities, and brand information through simple spreadsheet operations.

Getting Started
Dependencies

Before opening this project, make sure you have:

Windows 10 or above
Microsoft Excel 2016 or later
Basic knowledge of Excel formulas and tables
Installing
Download the Excel file from this repository.
Save the file to your computer.
Open the file using Microsoft Excel.
Enable editing if Excel shows a protected view warning.
Executing Program
Steps to Run the Project
Open the Excel workbook.
View the dataset sheet.
Use formulas to analyze the data.
Check category-wise products, prices, and quantities.
Example Formulas Used
SUM Formula
=SUM(D2:D34)
AVERAGE Formula
=AVERAGE(D2:D34)
COUNTA Formula
=COUNTA(B2:B34)
MAX Formula
=MAX(D2:D34)
MIN Formula
=MIN(D2:D34)
Help
Common Issues
Excel file not opening
Make sure Microsoft Excel is installed properly.
Formula not working
Check whether the formula starts with = symbol.
Verify the selected cell range.
Table formatting issue
Go to Table Design → Convert to Range if you want a normal table.
